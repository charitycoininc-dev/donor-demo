# Fix: Cargo.lock Version 4 Error

## The Problem
`cargo-build-sbf` from Solana 1.18.26 uses an old Rust toolchain that doesn't support lock file version 4 (generated by Cargo 1.87.0).

## Solution: Update Solana to Newer Version

### Option 1: Install Latest Solana (Recommended)

In **Administrator PowerShell**:

```powershell
cd C:\Users\myrew\Downloads
.\solana-install-init-x86_64-pc-windows-msvc.exe latest
```

Or check what the latest stable version is and install it.

### Option 2: Use Specific Newer Version

Try installing Solana 2.0 or newer which supports newer Cargo:

```powershell
cd C:\Users\myrew\Downloads
# Check what versions are available first
.\solana-install-init-x86_64-pc-windows-msvc.exe --help

# Then install a newer version like:
.\solana-install-init-x86_64-pc-windows-msvc.exe 2.0.0
```

### Option 3: Use Older Cargo (Workaround)

If you can't update Solana, downgrade Cargo to generate version 3 lock files:

```powershell
# Install rustup if needed
# Then install older Rust/Cargo
rustup install 1.70.0
rustup default 1.70.0

# Then build
cargo build-sbf --manifest-path programs/charity-coin-raffle/Cargo.toml
```

### Option 4: Manually Edit Lock File Format

1. Generate lock file with current Cargo
2. Manually edit first line from `version = 4` to `version = 3`
3. Try building (may have compatibility issues)

---

## Quick Fix: Delete Lock File and Update Solana

1. **Delete lock file:**
   ```powershell
   Remove-Item programs/charity-coin-raffle/Cargo.lock -Force
   ```

2. **Update Solana to latest:**
   ```powershell
   cd C:\Users\myrew\Downloads
   .\solana-install-init-x86_64-pc-windows-msvc.exe latest
   ```

3. **Close and reopen PowerShell**

4. **Build:**
   ```powershell
   $env:HOME = $env:USERPROFILE
   cargo build-sbf --manifest-path programs/charity-coin-raffle/Cargo.toml
   ```

---

## Why This Happens

- Your Cargo is version 1.87.0 (very new) → generates lock file version 4
- Solana 1.18.26 uses old Rust toolchain → only reads lock file version 3
- **Solution:** Update Solana to match your Cargo version

Try updating Solana first! 🚀
