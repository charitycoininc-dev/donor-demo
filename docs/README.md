# Documentation

This folder contains useful documents for the Charity Coin project.

## Folders

### franks_guide/
A complete web development guide that teaches programming from the ground up. This practical guide covers everything from HTML basics to building full-stack applications with databases. Perfect for beginners who want to learn by doing.

**Live guide:** [franksguide.surge.sh](https://franksguide.surge.sh)

### misc/
Random documents that were useful or may sometimes be useful. This folder contains unstructured documents that we use as a drop location for miscellaneous files, including architecture notes, migration guides, and development references.
