# Frank's Web Development Guide

A practical, hands-on guide to learning web development from the ground up.

**Live at:** [franksguide.surge.sh](https://franksguide.surge.sh)

## What's This?

This is my personal guide for learning web development - written the way I wish someone had taught me. No fluff, no buzzwords, just practical lessons that build on each other.

## The Lessons

1. **HTML Foundations** - Start here, build your first webpage
2. **CSS Styling** - Make things look good
3. **JavaScript Basics** - Add interactivity
4. **Terminal & Tools** - Navigate like a developer
5. **Complete Website Project** - Put it all together
6. **Vue Framework** - Modern web development
7. **State Management** - Handle complex data
8. **Data Manipulation** - Master JavaScript arrays
9. **Node.js Backend** - Server-side JavaScript
10. **Express APIs** - Build real backends
11. **SQLite Database** - Store data permanently
12. **Final Project** - Build something real

## How to Use This Guide

1. **Read** each lesson (15-30 minutes)
2. **Practice** with the exercises
3. **Test** your memory with the challenges
4. **Build** something real

Each lesson includes memory tests because knowing *when* to look things up is just as important as memorizing syntax.

## The Philosophy

- **Learn by doing**, not by reading
- **Start simple**, add complexity gradually
- **Make mistakes** - they're the best teachers
- **Build real things** from day one

## Getting Started

Visit [franksguide.surge.sh](https://franksguide.surge.sh) or start with `01-intro.md`.

Remember: Every expert was once a beginner who refused to give up.
